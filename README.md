## The line

> The dentist found a second row of teeth growing behind mine — and they were already chewing.

## How to run

```sh
python3 main.py
```

The program writes the single sentence to `/output/entry.txt`
(creating `/output` if needed). Stdlib only, offline, deterministic —
two runs produce byte-identical output.
